# Como aplicar a atualização

1. Feche o servidor e **faça backup** da sua pasta `django/` (principalmente `db.sqlite3`, `media/` e `.env`).
2. Extraia este zip **por cima** da sua pasta `django/` (aceite substituir os arquivos).
   O zip não traz `db.sqlite3`, `media/`, `.env` nem `venv/`, então nada seu é sobrescrito.
3. No terminal, com a venv ativada, dentro da pasta onde está o `manage.py`:

       pip install -r requirements.txt
       python manage.py migrate
       python manage.py runserver

4. Testes automáticos: `python manage.py test`

# Cadastrar / editar / excluir integrantes pelo site (Supabase)

O site já tem as telas de Equipe (adicionar, editar, excluir). Se ao salvar aparecer erro
(ex.: "O Supabase bloqueou a gravação" ou "não alterou nenhum registro"), o motivo é que o
Supabase só deixou LER a tabela. É preciso liberar a escrita:

## Passo 1 — testar o que está bloqueado
No terminal do projeto:

       python manage.py testar_supabase

Ele tenta ler, cadastrar, editar e excluir e diz qual passo falhou (e apaga a linha de teste no fim).

## Passo 2 — liberar a escrita no Supabase
Painel do Supabase → **SQL Editor** → **New query** → cole, rode (**Run**):

       alter table public.integrantes enable row level security;

       create policy "integrantes_leitura"  on public.integrantes for select using (true);
       create policy "integrantes_inserir"  on public.integrantes for insert with check (true);
       create policy "integrantes_editar"   on public.integrantes for update using (true) with check (true);
       create policy "integrantes_excluir"  on public.integrantes for delete using (true);

(Se aparecer "policy ... already exists", apague a antiga em *Authentication → Policies* ou
mude o nome entre aspas.)

> Alternativa mais segura: no `.env`, em `SUPABASE_KEY`, usar a chave **service_role**
> (Project Settings → API). Ela fica só no servidor Django e já ignora o RLS.
> Nunca publique o `.env` no GitHub se usar essa chave.

## Passo 3 — se o erro for na coluna `id`
Se aparecer "A coluna 'id' ... não gera número sozinha", rode no SQL Editor:

       alter table public.integrantes
         alter column id add generated by default as identity;

(Se der erro de sequência, crie a tabela de novo com `id bigint generated by default as identity primary key`.)

## Colunas esperadas na tabela `integrantes`
`id`, `nome`, `cargo`, `biografia`, `foto_url`

# Outras observações
- O `.env` precisa ter `SUPABASE_URL` e `SUPABASE_KEY`.
- O e-mail de "Esqueceu a senha" aparece **no terminal** do servidor (EMAIL_BACKEND de console).
- Para o login de **administrador** ir ao painel do Django, o usuário precisa ser superusuário/staff
  ou ter Perfil "administrador".
- Esqueceu a senha do admin? `python manage.py changepassword admin`
